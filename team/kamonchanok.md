# Pragmatic Promise

อยากเรียนรู้วิธีการทำงานร่วมกันในทีมซอฟต์แวร์อย่างเป็นระบบ ตลอดจนการออกแบบโครงสร้างโค้ดที่มีคุณภาพและการนำเครื่องมืออย่าง Git และ CI/CD มาใช้ในกระบวนการพัฒนาจริง เพื่อพัฒนาตนเองให้เป็นโปรแกรมเมอร์ที่ทำงานได้อย่างมืออาชีพ

# Broken Window ที่เคยเจอ
* **Window คืออะไร:** เคยปล่อยให้ไฟล์ตั้งชื่อไม่เป็นระบบ เช่น final_v1.js, final_final.js ในโปรเจกต์เก่า
* **ผลกระทบ:** ทำให้สมาชิกในทีมเกิดความสับสน นำไฟล์ผิดเวอร์ชันไปพัฒนาต่อ จนเกิดข้อผิดพลาดรุนแรงที่หาจุดแก้ได้ยาก
* **ถ้าแก้ทันทีจะป้องกันอะไร:** หากกำหนดข้อตกลงในการตั้งชื่อไฟล์และนำ Version Control มาใช้ตั้งแต่แรก จะป้องกันความสับสน ช่วยให้ติดตามประวัติการแก้ไขได้ง่าย และลดเวลาในการแก้บั๊กที่ไม่จำเป็น
