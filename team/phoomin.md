Pragmatic Promise

ถ้าทำส่วนไหนพลาดหรือรู้ตัวว่างานส่งไม่ทันแน่ๆ จะไม่เงียบและไม่แก้ตัวครับ จะรีบบอกเพื่อนในทีมทันทีเพื่อจะได้ช่วยกันหาทางแก้ หรือเอาแผนสองมาใช้ งานจะได้ไม่ลากยาวจนกระทบภาพรวม

ทำไมอยากเรียน SE

อยากรู้วิธีทำงานสายโปรแกรมเมอร์แบบเป็นระบบครับ ไม่อยากทำแบบสะเปะสะปะ อยากใช้ Git ทำงานร่วมกับคนอื่นเป็น อยากลุยเรื่อง CI/CD และเขียนโค้ดให้สะอาด อ่านง่าย ลอจิกดี จะได้ทำงานกับทีมอื่นได้แบบชิลๆ มืออาชีพขึ้น

Broken Window ที่เคยเจอ

Window คืออะไร: เคยเขียนโค้ดแบบแก้ไปเรื่อยๆ กองไว้ในคอมมิตเดียว แล้วพิมพ์ Commit Message มั่วๆ ส่งไป เช่น fix, work, asdf

ผลกระทบ: พอโค้ดพังขึ้นมาแล้วหาจุดแก้ไม่เจอ ย้อนเวอร์ชันก็ไม่ได้ ต้องมานั่งไล่ดูทีละบรรทัด มึนทั้งตัวเองทั้งเพื่อนในทีม

ถ้าแก้ทันทีจะป้องกันอะไร: ถ้าตกลงเรื่องการแบ่ง Commit การดัน Branch ให้เป็นระเบียบแต่แรก จะช่วยประหยัดเวลาชีวิตไปได้เยอะมาก ไม่ต้องมานั่งหัวร้อนไล่แก้บั๊กที่หาต้นตอไม่เจอ
