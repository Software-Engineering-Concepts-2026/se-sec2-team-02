# Non-Functional Requirements (NFR): Community Connector

### 1. Performance (ประสิทธิภาพการทำงาน)
* **NFR-01:** ระบบต้องประมวลผลและแสดงผลการค้นหางาน (Response Time) ได้ภายใน **< 2 วินาที** ที่ Percentile 95 (p95) เมื่อค้นหาในฐานข้อมูลขนาดไม่เกิน 1,000 รายการ

### 2. Security (ความปลอดภัย)
* **NFR-02:** การจัดเก็บรหัสผ่านผู้ใช้ต้องทำการ Hash ด้วยอัลกอริทึมที่ปลอดภัย (เช่น bcrypt) และรหัสผ่านต้องมีความยาวอย่างน้อย **≥ 8 ตัวอักษร**
* **NFR-03:** ระบบต้องกำหนด Session Timeout บังคับให้ออกจากระบบโดยอัตโนมัติเมื่อผู้ใช้งานไม่มีการเคลื่อนไหวเกิน **30 นาที**

### 3. Scalability & Availability (การรองรับขยายตัวและการพร้อมใช้งาน)
* **NFR-04:** ระบบต้องรองรับผู้ใช้งานพร้อมกัน (Concurrent Users) ได้อย่างน้อย **100 คน** โดยที่ระบบไม่ล่มหรือแสดงข้อความผิดพลาด
* **NFR-05:** ระบบต้องมีอัตราการพร้อมใช้งาน (Uptime) ไม่ต่ำกว่า **99%** ในช่วงเวลา 08:00 - 22:00 น. ของทุกวัน

### 4. Usability (ความง่ายในการใช้งาน)
* **NFR-06:** นิสิตที่เป็นผู้ใช้ใหม่ต้องสามารถทำภารกิจหลัก เช่น การค้นหางานและกดสมัครงานสำเร็จได้ภายในเวลา **≤ 3 นาที** โดยไม่ต้องอ่านคู่มือ
