# Phubbing & Focus Note

Phubbing คือพฤติกรรมการหันไปสนใจโทรศัพท์หรือการแจ้งเตือนจนละเลยกิจกรรมที่กำลังทำอยู่ ในบริบทของ Job Wanted UP ปัญหานี้เกิดขึ้นได้เมื่อแนนกำลังเรียนหรืออ่านหนังสือ แต่ได้รับข้อความจากกลุ่มประกาศงานจำนวนมาก

ระบบจึงควรลดสิ่งรบกวนด้วยการแสดงเฉพาะการแจ้งเตือนที่เกี่ยวข้องกับงานที่ผู้ใช้บันทึกหรือสมัครไว้ จัดกลุ่มการแจ้งเตือนให้สั้นและอ่านง่าย และให้ผู้ใช้เลือกปิดเสียงหรือกำหนดช่วงเวลาที่ไม่ต้องการรับการแจ้งเตือนได้ แนวทางนี้เชื่อมโยงกับความต้องการของ Persona หลักใน [personas.md](personas.md)
