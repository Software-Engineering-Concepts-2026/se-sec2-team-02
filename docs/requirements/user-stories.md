# User Stories: Community Connector

### Story US-01: ค้นหางานตามตัวกรองช่วงเวลาและสถานที่
As a น้องมิ้นท์  
I want ค้นหาและกรองประกาศงานพาร์ตไทม์ตามช่วงเวลาว่างและสถานที่ใกล้ ม.พะเยา  
So that สามารถเลือกงานที่ไม่กระทบเวลาเรียนได้  

**Acceptance Criteria:**
- [ ] Given อยู่หน้าค้นหางาน When เลือกตัวกรองสถานที่ "หน้า ม.พะเยา" และเวลา "17:00-21:00 น." Then ระบบแสดงเฉพาะงานที่ตรงเงื่อนไข
- [ ] Given ไม่พบงานที่ตรงกับเงื่อนไข When ระบบค้นหาเสร็จสิ้น Then แสดงข้อความ "ไม่พบงานที่ตรงกับเงื่อนไข" พร้อมปุ่มล้างตัวกรอง

**Priority:** Must  
**Estimate:** M  

---

### Story US-02: ดูรายละเอียดประกาศงานและค่าตอบแทน
As a น้องมิ้นท์  
I want ดูรายละเอียดงาน หน้าที่ความรับผิดชอบ และอัตราค่าตอบแทน  
So that ประเมินความเหมาะสมก่อนกดสมัครงาน  

**Acceptance Criteria:**
- [ ] Given นิสิตกดเลือกประกาศงานที่สนใจ When หน้าต่างรายละเอียดแสดงผล Then ต้องเห็นอัตราค่าตอบแทน (บาท/ชม. หรือ บาท/วัน) และเวลาทำงานชัดเจน
- [ ] Given นิสิตกดดูรายละเอียดงาน When อ่านข้อมูลเสร็จ Then มีปุ่ม "สมัครงาน" แสดงผลชัดเจนด้านล่าง

**Priority:** Must  
**Estimate:** S  

---

### Story US-03: ยื่นสมัครงานพาร์ตไทม์
As a น้องมิ้นท์  
I want กดสมัครงานพร้อมแนบข้อมูลติดต่อและตารางเรียนเบื้องต้น  
So that ผู้ว่าจ้างสามารถพิจารณาคุณสมบัติได้ทันที  

**Acceptance Criteria:**
- [ ] Given นิสิตเข้าสู่ระบบเรียบร้อยแล้ว When กดปุ่ม "สมัครงาน" Then ระบบบันทึกการสมัครและส่งข้อมูลให้ผู้ว่าจ้าง
- [ ] Given นิสิตยังไม่ได้เข้าสู่ระบบ When กดปุ่ม "สมัครงาน" Then ระบบแจ้งเตือนให้เข้าสู่ระบบก่อน

**Priority:** Must  
**Estimate:** M  

---

### Story US-04: ระบบอัปเดตสถานะประกาศงานเต็มแบบ Real-time
As a น้องมิ้นท์  
I want เห็นสถานะประกาศงานที่ปิดรับหรือคนเต็มแล้วทันที  
So that ไม่เสียเวลาส่งใบสมัครในตำแหน่งที่รับคนครบแล้ว  

**Acceptance Criteria:**
- [ ] Given ประกาศงานรับสมัครคนครบจำนวนแล้ว When นิสิตเปิดดูประกาศนั้น Then ปุ่มกดสมัครเปลี่ยนเป็นสีเทาและแสดงคำว่า "ปิดรับสมัครแล้ว"
- [ ] Given นิสิตกำลังกดสมัครในจังหวะที่คนเต็มพอดี When ระบบประมวลผล Then แจ้งเตือนข้อความ "ขออภัย ตำแหน่งนี้เต็มแล้ว"

**Priority:** Should  
**Estimate:** L  

---

### Story US-05: โพสต์สร้างประกาศรับสมัครงาน
As a พี่เอก  
I want สร้างประกาศรับสมัครงานพาร์ตไทม์ระบุเงื่อนไขและจำนวนรับ  
So that ได้นิสิตมาช่วยงานในร้านได้ทันเวลา  

**Acceptance Criteria:**
- [ ] Given ผู้ประกอบการกรอกข้อมูลหัวข้องาน ค่าตอบแทน เวลาทำงาน และจำนวนที่ต้องการครบถ้วน When กด "เผยแพร่" Then ประกาศแสดงขึ้นบนระบบทันที
- [ ] Given ผู้ประกอบการกรอกข้อมูลไม่ครบถ้วน When กด "เผยแพร่" Then ระบบแสดงข้อความเตือนให้กรอกช่องที่เว้นว่างไว้

**Priority:** Must  
**Estimate:** M  

---

### Story US-06: จัดการและแก้ไขประกาศงาน
As a พี่เอก  
I want แก้ไขรายละเอียดข้อมูลในประกาศงานเดิมที่ลงไว้ได้  
So that สามารถอัปเดตข้อมูลเงื่อนไขให้ถูกต้องตรงกันเสมอ  

**Acceptance Criteria:**
- [ ] Given ผู้ประกอบการอยู่หน้างานของฉัน When แก้ไขรายละเอียดและกด "บันทึก" Then ข้อมูลใหม่แสดงผลแทนที่ข้อมูลเดิมทันที

**Priority:** Should  
**Estimate:** S  

---

### Story US-07: ตรวจสอบรายชื่อผู้สมัครและตอบรับเข้าทำงาน
As a พี่เอก  
I want ดูรายชื่อนิสิตที่สมัครเข้ามาและกดตอบรับหรือปฏิเสธได้  
So that สามารถคัดเลือกพนักงานพาร์ตไทม์เข้าทำงานได้อย่างเป็นระบบ  

**Acceptance Criteria:**
- [ ] Given มีผู้สมัครส่งใบสมัครเข้ามา When ผู้ประกอบการกด "ตอบรับ" Then สถานะผู้สมัครเปลี่ยนเป็น "รับเข้าทำงาน" และระบบแจ้งเตือนไปยังนิสิต

**Priority:** Must  
**Estimate:** M  

---

### Story US-08: ดูประวัติการสมัครงานของตนเอง
As a น้องมิ้นท์  
I want ตรวจสอบสถานะและประวัติการสมัครงานทั้งหมดที่เคยยื่นไว้  
So that ติดตามผลการคัดเลือกได้อย่างสะดวกรวดเร็ว  

**Acceptance Criteria:**
- [ ] Given นิสิตเข้าสู่ระบบแล้วเปิดหน้าประวัติการสมัคร When โหลดหน้าสำเร็จ Then แสดงรายการงานที่สมัครพร้อมสถานะ (รอพิจารณา/ตอบรับ/ปฏิเสธ)

**Priority:** Should  
**Estimate:** S
