# Project Proposal: Job Wanted UP

## 1. Theme: Community Connector

Job Wanted UP เป็นแพลตฟอร์ม Community Connector สำหรับเชื่อมต่อผู้ว่าจ้างกับผู้รับจ้างภายในชุมชนมหาวิทยาลัยพะเยา การใช้ Theme นี้ช่วยแก้ปัญหาการประกาศงานที่กระจัดกระจายอยู่ในกลุ่มแชตและโซเชียลมีเดีย โดยรวมการค้นหา การประกาศงาน การสมัครงาน และข้อมูลสถานที่ไว้ในระบบเดียว

## 2. Problem และ Target Persona

ผู้ใช้งานต้องการหางานพาร์ตไทม์หรือต้องการจ้างคนทำงานเล็ก ๆ แต่การค้นหาผ่านกลุ่ม Facebook หรือ Line OpenChat ทำให้ประกาศถูกดันหาย ข้อมูลเวลาและสถานที่ไม่ชัดเจน และตรวจสอบความน่าเชื่อถือได้ยาก

Persona หลักคือ **นันทิดา หรือ “แนน”** นิสิตชั้นปีที่ 2 อายุ 20 ปี คณะบริหารธุรกิจ มหาวิทยาลัยพะเยา เธอสลับบทบาทเป็นผู้รับจ้างเพื่อหารายได้เสริม และเป็นผู้ว่าจ้างในช่วงที่ต้องการประหยัดเวลาจากการทำธุระระหว่างสัปดาห์สอบ

## 3. Value Proposition

Job Wanted UP เป็นตัวกลางที่ช่วยให้ผู้ใช้ค้นหาและประกาศงานในเว็บเดียว พร้อมข้อมูลประเภทงาน ค่าตอบแทน เวลา สถานที่ และระยะทางที่ชัดเจน ผู้รับจ้างจึงเลือกงานที่เหมาะกับตารางชีวิตได้ง่าย ส่วนผู้ว่าจ้างสามารถหาคนในชุมชนใกล้เคียงได้อย่างเป็นระบบและน่าเชื่อถือมากขึ้น

## 4. MoSCoW Priorities

### Must Have

- ระบบแบ่ง Role ระหว่างผู้ว่าจ้างและผู้รับจ้าง
- ระบบ Card สำหรับแสดงประกาศงาน
- ระบบสมัครงานและจัดการสถานะผู้สมัคร
- ระบบ Search และ Filter ตามประเภทงาน เวลา และสถานที่

### Should Have

- ระบบคำนวณระยะห่างระหว่างผู้รับจ้างกับสถานที่ทำงาน
- ระบบแสดงข้อมูลผู้ใช้งานและประวัติการสมัครงาน
- การแจ้งเตือนเมื่อประกาศหรือสถานะการสมัครเปลี่ยนแปลง

### Could Have

- การแชร์ประกาศงานผ่าน Link หรือ QR Code
- ระบบให้คะแนนและรีวิวหลังจบงาน
- แผนที่แบบ Interactive สำหรับช่วยเลือกงานใกล้ตัว

### Won't Have This Term

- ระบบ AI ตรวจสอบความถูกต้องของงานที่ผู้รับจ้างทำ
- ระบบชำระเงินหรือ Escrow อัตโนมัติเต็มรูปแบบ

## 5. Risks

- ขอบเขตของระบบอาจใหญ่เกินเวลาที่มีใน Sprint สุดท้าย
- ฟีเจอร์ Mapping และการคำนวณระยะทางอาจขึ้นอยู่กับบริการภายนอกและข้อจำกัดของ API
- ข้อมูลประกาศหรือข้อมูลผู้ใช้อาจไม่ครบถ้วน ทำให้การค้นหาและการจับคู่ไม่แม่นยำ

## 6. Assumptions และ Scope

- ผู้ใช้งานมีโทรศัพท์มือถือและสามารถเข้าถึงอินเทอร์เน็ตได้
- การใช้งานระยะแรกมุ่งเน้นชุมชนรอบมหาวิทยาลัยพะเยา
- ผู้ใช้กรอกประเภทงาน เวลา ค่าตอบแทน และสถานที่ด้วยตนเอง
- Sprint นี้เน้นการค้นหา ประกาศ สมัครงาน และจัดการสถานะเป็นหลัก ส่วน AI และการชำระเงินอัตโนมัติอยู่นอกขอบเขต
