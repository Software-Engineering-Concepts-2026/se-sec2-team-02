ชื่อโปรเจกต์ : Job Wanted UP

Persona หลัก (กลุ่มเป้าหมาย) : นันทิดา หรือที่เพื่อนๆ เรียกกันว่า "แนน" เป็นนิสิตชั้นปีที่ 2 วัย 20 ปี คณะบริหารธุรกิจ มหาวิทยาลัยพะเยา 

Value proposition (ปัญหาที่แก้ + คุณค่าที่ได้) : Job Wanted จะเป็นตัวกลางในการหาคนทำงาน และใช้เป็นตัวกลางในการจ้างงานที่มีความน่าเชื่อถือ หรือใช้ในการหางานในเว็บเดียว ทำให้ช่วยแบ่งเบาภาระากการทำงานเล็กน้อยๆโดยที่บางงานอาจจะต้องใช้เวลาในการทำงานมากพอสมควร ในเว็บจะแบ่ง 2 โหมด คือผู้รับจ้าง และโหมดผู้ว่าจ้าง มีการจัดหมวดหมู่งานที่ต้องการ

MoSCoW (ฟีเจอร์ไหน ต้องมี/ควรมี/อาจจะมี/ไม่ทำ) : ระบบแบ่ง role ของผู้ใช้งาน, ระบบ card แสดงประกาศต่างๆของทั้งผู้ว่าจ้าง และของผู้รับจ้าง, ระบบ search หา card หรือโพสงานที่ต้องการ, ระบบการ filter card หรือ ประกาศหางาน, ระบบ mapping และคำนวนระยะห่างระหว่างผู้รับจ้างกับสถานที่จ้าง/สิ่งที่จะไม่ทำคือ ระบบ AI ในการตรวจสอบความถูกต้องของงานที่ผู้รับจ้างทำ

Risks & assumptions (ความเสี่ยง) : ความเสี่ยงของขนาดของโปรเจ็คที่อาจจะใหญ่เกิน และอาจจะทำให้ไม่ทันกำหนดของการทำ sprit สุดท้าย
